# Reference image sources: Raml heritage car 601

The reference photographs used for this model are **not included** in the repository (they belong to their
authors; several are "all rights reserved, reference use only"). This file lists each one with its source page,
author and licence so it can be re-downloaded. The full metadata (image URL, size, view, fleet number, notes) is
in the CSV manifests in `manifests/`. To rebuild the photo underlays, download the images into
`references/images/<set>/<filename>` (gitignored) and run the scripts in `notes/photogrammetry/`.

22 images in total.
